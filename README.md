# Alpha Mining Frontend

Alpha Mining Frontend is a multi-tenant, production-ready web application built with Nuxt.js, providing interactive dashboards and real-time analytics for mining operations, including production monitoring, geology insights, and inventory tracking.

## 🚀 Features

- Multi-tenant ready (subdomain-based)
- Interactive dashboards (production, geology, analytics)
- Real-time data visualization (charts & KPIs)
- Responsive UI (desktop & tablet friendly)
- Dynamic filtering (date, IUP, category, etc.)
- Authentication with JWT (access & refresh token)
- Integration with Django REST API backend

## 🏗️ Tech Stack

- Nuxt.js 3 / 4
- Vue 3 (Composition API)
- Tailwind CSS
- Pinia (state management)
- ApexCharts / Plotly (data visualization)
- shadcn-vue (UI components)
